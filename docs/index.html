Projeto de Extensão ASP.NET Core 8 SQLite

Biblioteca Online

Sistema web completo para gestão de acervo e empréstimos de livros, com dois perfis de usuário, fluxo de aprovação e painel administrativo.

O que o sistema faz

Funcionalidades principais

Dois perfis de acesso com responsabilidades distintas

Perfil Leitor

  • Cadastro e login próprios
  • Consulta ao acervo com busca e filtros
  • Solicitação de empréstimo (aguarda aprovação)
  • Acompanhamento de empréstimos em aberto
  • Renovação (se não estiver atrasado)
  • Devolução e histórico de empréstimos

Perfil Administrador

  • Painel com KPIs (acervo, ativos, atrasos)
  • Aprovação e rejeição de solicitações
  • CRUD completo de livros e usuários
  • Criação direta de empréstimos
  • Histórico completo de todas as operações
  • Gerenciamento de outros administradores

Fluxo do leitor

Cadastro — cria conta com nome, e-mail e senha
Consulta — pesquisa livros por título, autor ou categoria
Solicitação — pede empréstimo; status fica "Pendente"
Aprovação — administrador aprova; estoque é decrementado
Devolução — leitor ou admin registra; estoque volta

Persistência de dados

O sistema usa SQLite — um banco relacional embutido que grava tudo em um único arquivo BibliotecaOnline.db. Não é necessário instalar servidor de banco de dados separado.

Na primeira execução, o Entity Framework Core aplica as migrações automaticamente e popula o banco com dados de exemplo (seed): 1 admin, 2 leitores, 5 livros e 5 empréstimos em estados variados.

Em produção, o caminho do arquivo pode ser configurado via variável de ambiente BIBLIOTECA_DB_PATH.

Desenvolvimento local

Como executar

3 comandos no terminal e o sistema está rodando

Pré-requisito: .NET 8 SDK instalado.

1 Restaurar dependências 
dotnet restore
2 Compilar o projeto 
dotnet build
3 Iniciar a aplicação 
dotnet run
Na primeira execução, o banco BibliotecaOnline.db é criado automaticamente e populado com dados de exemplo. Acesse http://localhost:5282. Login admin: admin@biblioteca.com / admin123
